Hub และทีม

ย้ายด้วยช่องท้ายป้ายชื่อ · ขอบน้ำเงิน = TM · ขอบม่วง = Hub RM · ขอบส้ม = ไม่มีเคสตัวเองใน พ.ย. · ขอบประ = ร้านต่างจังหวัดที่แยกให้ย้ายตามจังหวัดได้ · ขีดฆ่า = รอลาออก · ลบทีมแล้วคนไปอยู่ "ยังไม่มีทีม"

การเปลี่ยนแปลงเทียบตั้งต้น

เก็บโครงสร้างตั้งต้นไว้เสมอ ไม่ถูกแก้ · เทียบกับแผนอื่นได้ · แถวสีเหลือง = ทีมที่มีการเปลี่ยน · ตัวเลขสีเขียว/แดง = เพิ่ม/ลด

ตรวจกับไฟล์ HR

เทียบข้อมูลพนักงานในเครื่องมือกับไฟล์ MASTER Sales Name list ล่าสุด · การแก้ชื่อเล่น Base ตำแหน่ง ในตารางพนักงานบันทึกเป็น "สิ่งที่แก้" ใช้กับทุกแผน และไม่ถูกทับเมื่อนำเข้าไฟล์ HR ใหม่

โยกจังหวัด

ย้ายพนักงานและร้านแยกทั้งหมดที่อยู่ในจังหวัดนั้นไปทีมที่เลือกในครั้งเดียว (จะถามยืนยันก่อน และกดย้อนกลับได้) · ตัวเลขในวงเล็บ = จำนวนคน+ร้านในแต่ละทีม · จังหวัดของพนักงานคิดจาก Base แก้ได้ในตารางพนักงาน
